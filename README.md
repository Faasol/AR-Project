## How to test it
Select "Kitchen" scene from the Assets/Scenes folder and click play. If you want to visualize the simulated environment, open the "Kitchen_pesto" prefab in Assets/XR/Environments/ 
## Brief description
The objective of this project is to develop an interactive, marker-based Augmented Reality (AR) application designed to assist users through a real-world process: preparing traditional Genovese pesto. We defined an interactive 10-step guided pipeline that users can follow in their physical kitchen environment.
This allows the users to follow culinary steps hands-free, without relying on traditional text manuals or video screens.
Also note that when opened for the first time, there's some warnings that disappear once the Kitchen scene is loaded and played. We are sorry about this fact, but we couldn't find a way to avoid them.
